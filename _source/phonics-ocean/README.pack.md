# Phonics Ocean Resource Pack v2

Start with `GAMEPLAY_PHONICS_V2.md`.

- Visual source boards and sprite references: `ASSETS/`
- Level configs: `LEVEL_CONFIGS/`
- Word list: `DATA/word_bank.csv`
- Required pronunciation clips: `DATA/audio_manifest.csv`
- Research rationale: `DOCS/RESEARCH_NOTES.md`

Recommended workflow: render word labels in the game engine and use the fish sprites as reusable carriers. This lets you replace the weekly word list without redrawing art.
