# Phonics Ocean v3 – Separate Assets Pack

This pack contains separate high-resolution asset images for the redesigned **Phonics Ocean** project.
The goal is to avoid quality loss from cutting elements out of one huge concept board.

## Folder structure
- `backgrounds/` – 6 level backgrounds, each as a standalone 16:9 PNG
- `sheets/` – standalone sprite sheets on magenta background
- `docs/` – gameplay description and asset notes

## Main asset files
### Backgrounds
1. `coral_reef.png` – Level 1: shallow reef
2. `kelp_forest.png` – Level 2: kelp forest
3. `shipwreck_bay.png` – Level 3: shipwreck bay
4. `twilight_trench.png` – Level 4: trench
5. `abyss_cave.png` – Level 5: abyss cave
6. `volcanic_ruins.png` – Level 6: volcanic ruins

### Sheets
1. `player_fish_levels_sheet.png` – 6 player fish variants across levels
2. `word_fish_and_prey_sheet.png` – word carriers + edible fish
3. `predators_ui_items_effects_sheet.png` – predators, helpers, hazards, items, controls, UI, VFX

## Suggested usage
- Use the six backgrounds as the biome progression from shallow sea to deep ocean.
- Desktop mode: fish follows the mouse cursor directly.
- Mobile mode: easier controls with auto-swim forward + drag/tap assist.
- Word labels, score text, and gameplay text should be rendered in-engine for maximum flexibility.
